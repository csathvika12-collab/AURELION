# AURELION
AURELION is a modern, premium OTT (Over-the-Top) streaming platform frontend inspired by leading entertainment services such as Netflix. Built using React, Vite, and Tailwind CSS, the application delivers a fast, responsive, and visually engaging user experience with smooth animations powered by Framer Motion. The platform integrates with The Movie Database (TMDB) API to fetch real-time movie and TV show information, including trending content, top-rated titles, genres, and trailers.

The application includes a simulated user authentication system with login, signup, profile management, and persistent watchlists using localStorage. Users can browse content across multiple categories, search for movies and TV shows, view detailed information through interactive modals, and watch embedded trailers directly within the application. Advanced UI features such as animated page transitions, responsive layouts, genre and language filtering, and personalized "My List" functionality provide a seamless entertainment experience across desktop and mobile devices.

Developed with a scalable component-based architecture, AURELION demonstrates modern frontend development practices, reusable React components, client-side routing, state management, and API integration. The project showcases proficiency in building enterprise-quality user interfaces while emphasizing performance, accessibility, and responsive design. It serves as an excellent portfolio project for frontend and full-stack developers, highlighting skills in React ecosystem development, REST API consumption, UI/UX implementation, and modern web application architecture.
