# 🎬 AURELION — Premium OTT Streaming Platform

**AURELION** is a modern, premium **OTT (Over-the-Top) streaming platform** designed to provide an engaging movie and TV-show browsing experience. Inspired by popular streaming platforms, AURELION combines a responsive user interface, smooth animations, real-time entertainment data, personalized watchlists, and trailer playback into a single web application.

## ✨ Features

* 🎥 Browse movies and TV shows
* 🔥 Discover trending and popular content
* ⭐ Explore top-rated movies and shows
* 🔎 Search for movies and TV shows
* 🎭 Browse content by genres
* 🌎 Filter content by language
* ▶️ Watch movie and TV trailers
* ❤️ Personalized **My List / Watchlist**
* 👤 User login, signup, and profile management
* 💾 Persistent user data using local storage
* 📱 Responsive design for desktop and mobile devices
* ✨ Smooth animations and interactive UI
* 🧩 Reusable component-based architecture

## 🛠️ Tech Stack

### Frontend

* **React.js**
* **Vite**
* **Tailwind CSS**
* **Framer Motion**
* **React Router**
* **Lucide React**
* **React Player**

### Backend / Services

* **Python**
* **FastAPI**
* **MongoDB**
* **Motor**
* **JWT Authentication**
* **Resend**

### API

* **TMDB API** — Used to retrieve movie and TV-show information, genres, trending content, ratings, and trailer-related data.

## 🏗️ Architecture

AURELION follows a modern component-based web application architecture:

**User → React Frontend → API Integration → TMDB / Backend Services → Database → Personalized Experience**

The application separates UI components, routing, state management, API communication, authentication, and data persistence to provide a scalable development structure.

## 🚀 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js
* npm
* Python
* MongoDB

### Installation

Clone the repository:

```bash
git clone <repository-url>
cd AURELION
```

Install frontend dependencies:

```bash
npm install
```

Install backend dependencies:

```bash
pip install -r requirements.txt
```

Create and configure your environment variables, including the required API and database credentials.

Start the frontend:

```bash
npm run dev
```

Start the FastAPI backend using Uvicorn according to your backend configuration.
